# Schedules Example

Simple examples showing how to use the `schedules` package.

## Running the Example

```bash
dart run example/main.dart
```

## What's Included

- **One-time events**: Birthdays, appointments
- **Daily schedules**: Workouts, medication
- **Weekly schedules**: Meetings, work days
- **Monthly schedules**: Rent, bills
- **Date ranges**: Get occurrences between dates
- **Exclusions**: Skip holidays, sick days
- **Real-time checking**: Is today a work day?

The example shows practical use cases like payroll schedules, work days with holidays, and checking if events occur on specific dates.
